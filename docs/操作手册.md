# 高校智能排考管理平台 - 操作手册

## 环境要求

- Python 3.11+
- PostgreSQL 15+
- Docker & Docker Compose（可选）
- Google OR-Tools（CP-SAT 求解器）

---

## 一、数据库操作

### 1.1 连接数据库

#### 本地开发环境

```bash
# 使用 psql 直接连接
psql -h localhost -U scheduler -d exam_scheduler

# 输入密码后进入交互式终端
```

#### Docker 环境

```bash
# 进入容器内连接
docker-compose exec db psql -U scheduler -d exam_scheduler

# 或者在宿主机直接连接（需确保 5432 端口已映射）
psql -h localhost -p 5432 -U scheduler -d exam_scheduler
```

### 1.2 初始化数据库

```bash
# 先确保 .env 文件存在并配置了数据库连接
# 然后执行初始化脚本

# 本地开发
python scripts/init_db.py

# Docker 环境
docker-compose exec api python scripts/init_db.py
```

### 1.3 生成测试数据

```bash
# 确保时段数据已初始化（参考上一节）
python scripts/generate_test_data.py

# Docker 环境
docker-compose exec api python scripts/generate_test_data.py
```

### 1.4 数据库迁移（Alembic）

```bash
# 查看当前迁移状态
alembic current
alembic history --verbose

# 生成新迁移（当模型变更后）
alembic revision --autogenerate -m "描述迁移内容"

# 执行迁移
alembic upgrade head

# 回滚到上一版本
alembic downgrade -1

# 生成 SQL 脚本（离线迁移）
alembic upgrade head --sql > migration.sql
```

## 二、应用启动

### 2.1 本地开发模式

```bash
# 1. 确保 .env 文件存在
cp .env.example .env
# 编辑 .env 填入实际数据库密码

# 2. 安装依赖
pip install -r requirements.txt

# 3. 初始化数据库（首次）
python scripts/init_db.py

# 4. 启动 FastAPI 服务
uvicorn app.main:app --reload --port 8000

# 5. 访问前端
# 浏览器打开 http://localhost:8000
```

### 2.2 Docker Compose 模式

```bash
# 1. 确保 .env 文件存在并配置了 POSTGRES_PASSWORD
cp .env.example .env
# 编辑 .env，修改 POSTGRES_PASSWORD 为实际密码

# 2. 启动所有服务
docker-compose up -d

# 3. 查看服务状态
docker-compose ps

# 4. 查看日志
docker-compose logs -f api

# 5. 停止服务
docker-compose down
```

## 四、环境变量说明

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `POSTGRES_USER` | PostgreSQL 用户名 | `scheduler` |
| `POSTGRES_PASSWORD` | PostgreSQL 密码 | `your-secure-password` |
| `POSTGRES_DB` | 数据库名 | `exam_scheduler` |
| `SCHEDULER_DATABASE_URL` | 异步数据库连接（FastAPI 用） | `postgresql+asyncpg://...` |
| `SCHEDULER_DATABASE_SYNC_URL` | 同步数据库连接（脚本/Alembic 用） | `postgresql://...` |
| `SCHEDULER_DEBUG` | 调试模式 | `true` / `false` |
| `SCHEDULER_SECRET_KEY` | JWT 签名密钥 | `your-secret-key` |
| `SCHEDULER_MAX_SOLVE_TIME` | 排考求解超时（秒） | `300` |

### 配置优先级

```
环境变量 > .env 文件 > 代码默认值
```

> ⚠️ 注意：`SCHEDULER_DATABASE_URL` 和 `SCHEDULER_DATABASE_SYNC_URL` **必须**通过环境变量或 `.env` 文件设置，不再有硬编码回退值。

## 五、前端操作

### 5.1 排考流程

1. **基础数据管理**：在「课程管理」「教室管理」「教师管理」中录入基础数据
2. **排考参数配置**：设置约束规则（教室容量匹配、连续监考限制、AB卷分配等）
3. **开始排考**：点击「开始排考」，等待求解器完成
4. **查看结果**：在排考结果页面查看生成的考试安排
5. **手动微调**：支持调时段、换教室、换教师等微调操作

### 5.2 常见操作入口

- 排考界面：`/`（首页）
- 课程管理：`/api/courses`
- 教室管理：`/api/classrooms`
- 教师管理：`/api/teachers`
- 排考结果：`/api/schedule/result`

## 六、GitHub 协作

### 6.1 首次推送（需要先配置远程仓库）

```bash
# 添加远程仓库（请将 URL 替换为你的仓库地址）
git remote add origin https://github.com/你的用户名/exam-scheduler.git

# 推送所有分支
git push -u origin master
```

### 6.2 后续提交推送

```bash
# 查看状态
git status

# 添加文件
git add .

# 提交
git commit -m "描述你的更改"

# 推送
git push
```

### 6.3 ⚠️ 安全注意事项

- **`.env` 文件包含真实数据库凭据**，已被 `.gitignore` 排除，切勿强制添加！
- `.env.example` 仅作为模板，不包含真实密码，可以安全提交
- 生产环境建议使用 Docker Secrets 或专门的密钥管理服务
