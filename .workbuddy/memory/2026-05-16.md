### Bug 修复：首页操作记录显示 undefined
**问题描述**：
- 首页最新操作记录显示 `undefined - exam_teacher` 和 `undefined - exam`

**根本原因**：
- 后端 API 返回的字段名与前端期望不一致
- 后端返回：`action`, `entity_type`, `entity_id`
- 前端期望：`operation_type`, `operation_type_display`, `entity_name`

**修复方案**：
- 修改 `app/routers/audit_logs.py`，添加以下字段：
  - `operation_type`: 操作类型标识
  - `operation_type_display`: 操作类型中文显示（如：教师调剂、教师变更）
  - `entity_name`: 实体名称（如：考试: 大学英语读写1/2）
- 实现 `get_entity_name()` 函数，关联查询获取实体名称
- 添加 `ACTION_DISPLAY_MAP` 操作类型中文映射表
- 处理实体已被删除的情况，显示（已删除）提示
